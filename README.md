Super Brain

A small 2.5D platformer made in GNU Octave by Loic Loblot and Loann Ravel for the university unit Techniques for Empirical Research.

You play a little brain going through school, from Kindergarten to University. Collect books, avoid or stomp viruses, cross holes using stones and moving platforms, and beat the final boss to graduate. The brain grows a bit at each level, and every level is harder than the last one.

How to play

Open super_brain_VF.m in Octave (tested with version 10.1.0) and run it.

Left / Right arrows (or Q / D): run

Up arrow, Z or Space: jump

P: pause, Esc: stop the game

At the end of a game: R to replay, Q to quit

Rules

You start with 5 hearts for the whole game (+1 heart after levels 2 and 4).

Falling in a hole, or touching a spike or a virus, costs one heart.

Jump on green viruses to destroy them. Red and flying viruses can't be stomped, so avoid them.

Collect enough books to open the flag at the end of each level.

Coffee cups make you invincible for a few seconds.

On the last level, stomp the boss 3 times before reaching the flag.

Levels are randomly generated, so each new game is different. 

super_brain_VF.m: the final version of the game.

We used AI (Claude, ChatGPT) to write a large part of the code. Our work was to test the game, find the errors, decide what to change or improve, and check and adapt the code until it worked the way we wanted.
Hope you enjoy it!
